# 方法与实现边界

## 原型学习是独立分支

Stage1以监督训练过的R50检测器为起点，仅训练原型投影/归一化相关参数，检测器及BN冻结；十类各10个原型。Stage2从完整Stage1检查点继续，在6000帧有标注数据上新增6000步，累计12000步。它不是在线EMA半监督训练。

Stage2包含正样本原型学习、原型约束、明确负样本排斥和分类别自适应负损失权重。当前初值0.05、上调步长0.02、范围0.005–0.10；正样本保护条件触发时减半并受下界约束。具体判据以当前头文件和配置为准，不与Mini历史参数混用。银行原型更新和梯度参数更新也应区分。

冻结检测器时，不能把不同随机输入或不同时序协议下的mAP/NDS差异归因于原型学习改进。

## 在线教师–学生分支

教师对无标注帧在线生成候选伪标签，学生按真/伪样本交替进行优化尝试，随后教师按EMA更新。当前EMA系数0.999。12000次交替尝试名义上各6000次，但空伪标签可能导致跳过更新；不能把尝试步数直接当作有效优化次数。

当前全局增强配置采用score>0.2的候选门槛，伪标签分支损失权重0.25，不表示这是已经证明最优的阈值。真标签与伪标签监督不同：无可信2D GT时不伪造二维监督；三维融合损失仍可能回传到允许训练的图像模块。

增强保持教师/学生共享几何关系，再给学生增加输入信息扰动：全图亮度、对比度、饱和度，全局随机位置的局部遮挡/马赛克/模糊，全局随机丢点和逐点XYZ小范围噪声。没有独立平移教师伪标签框，也没有独立移动整场景或目标。

## 仍未完成的连接

最终目标是保留高置信度候选，再利用类别原型相似度挖掘0.2–0.8区间的可靠候选。但原型筛选尚未接入当前EMA伪标签生产链路。检测器经SSL更新后，旧原型空间并不会自动与新特征空间对齐，必须单独验证适配。

原型相似度提供的是语义一致性信息，不等于定位IoU、目标存在概率或真实框正确概率。相似度阈值需要在验证集校准，不在内部测试集上选择超参数。
